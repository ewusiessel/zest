🧠 Project Thinking
This wasn’t just about building a website — it was about solving a problem:
How can a beauty brand present its services online in a way that feels trustworthy, calming, and easy to navigate?
Key decisions:
Minimalist layout → reduces clutter and keeps focus on services
Soft visual hierarchy → guides users naturally through content
Service-based structure → aligns with how customers search (Hair / Wellness / Beauty)
Responsive design → ensures accessibility across all devices

💡 Features
